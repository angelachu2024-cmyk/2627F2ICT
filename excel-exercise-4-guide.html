Use IF to determine Credits Granted

Enter an IF statement for the first student in the column “Credits Granted” that will produce 3 if the final average is greater than or equal to the class average, and 0 if it is not.

Why absolute reference? Without the dollar signs, the reference would shift to B13, B14, etc., giving wrong results. $B$12 locks the row and column.
Check resultsStudents with avg above the class average should get 3 credits, others 0.
