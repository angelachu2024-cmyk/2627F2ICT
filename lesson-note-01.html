01

The Excel Window

Learn the main parts of the Excel window and how to identify columns, rows, and cells.

Key Parts of the Window

  • Title Bar （標題列） – shows the workbook name.
  • Menu Bar （功能區） – contains tabs like Home, Insert, Data.
  • Formula Bar （公式列） – shows the content of the active cell.
  • Sheet Tabs （工作表標籤） – at the bottom, e.g. Sheet1, Sheet2.
  • Cell （儲存格） – the intersection of a row and a column where data is entered.
  • Status Bar （狀態列） – displays information about the current mode and quick calculations.
  • Row （列） – a horizontal group of cells, identified by numbers (1, 2, 3, …).
  • Column （欄） – a vertical group of cells, identified by letters (A, B, C, …).
  • Name Box （名稱方塊） – shows the address or name of the selected cell.
💡 Each excel file is known as a workbook which is like a notebook. Inside the workbook are sheets, called worksheets. A new workbook can add additional worksheets as long as there is memory space on your computer.

02

The Worksheet （工作表）

Understand the grid structure: columns, rows, and the huge number of cells available.

Worksheet size

16,384 columns × 1,048,576 rows = ~17.18 billion cells （超過 171 億個儲存格）
  • The worksheet is organized into a rectangular grid 正方形格子 containing columns 欄 and rows 行.
  • Column （欄） – vertical group, labelled with letters.
  • Row （列） – horizontal group, labelled with numbers.
  • Cell （儲存格） – the intersection of one column and one row.
💡 This is a very large space – enough for school timetables, class marks, or even entire library catalogues!

Navigating the worksheet

  • Click a cell to select it （選取）.
  • Use the arrow keys （方向鍵） to move.
  • Press Ctrl + Home to go to cell A1.
  • Press Ctrl + End to go to the last used cell.
  • Use the scroll bars （捲軸） to move around.
▶ Excel 2024 vs Excel 365 – worksheet navigation
  • Shortcuts: The keyboard shortcuts are the same in both versions.

Cell References （儲存格參照）

Every cell has a unique address. Learn how to read and write them correctly.

Format: ColumnLetter + RowNumber

  • Examples: A1, B5, Z100, AA2.
  • Always write the column letter （欄字母） first.
  • Then write the row number （列數字）.
  • The address never has a space in between (e.g., ✗ B 3 → ✓ B3).
Examples of cell addresses
ABCD
1A1B1C1D1
2A2B2C2D2
3A3B3C3D3

Highlighted cells show their addresses: A1, B2, C3.

Quick practice

Which cell is at column D, row 7?

D7

Which cell address is column Z, row 10?

04

Align Labels （對齊標籤）

Make your tables neat and professional by aligning text correctly.

Alignment buttons on the Home tab

  • Select the cell(s) you want to format.
  • Click the alignment button on the Home tab.

Vertical Alignment

Align Top （靠上對齊）
Middle Align （垂直置中）
Align Bottom （靠下對齊）

  • Align Top: Puts content at the top of the cell; best for dates.
  • Middle Align: Puts content in the middle of the cell; best for numbers.
  • Align Bottom: Puts content at the bottom of the cell; best for long text.

Horizontal Alignment

Align Left （靠左對齊）
Center （置中對齊）
Align Right （靠右對齊）

  • Center: Puts content in the middle across the cell; best for titles or short codes.
  • Align Left: Puts text on the left side of the cell; best for names and words.
  • Align Right: Puts numbers on the right side; best so decimal points line up nicely.

Extra Alignment Tools

Wrap Text （自動換行）
Merge & Center （合併置中）
Indent （縮排）

  • Wrap Text: Makes long sentences fit by splitting them into multiple lines inside the same cell.
  • Merge & Center: Combines multiple cells into one large cell and centers the text.
  • Indent: Adds a small space between the cell border and your text.

💡 Tip: Numbers are automatically right‑aligned in Excel. Text labels are automatically left‑aligned – but you can change them!

Example

Name (Center) Score (Right)
Alice 95
Bob 82

Headings are centered, scores are right‑aligned.

▶ Excel 2024 vs Excel 365 – alignment
  • Alignment gallery: Excel 365 has a slightly different icon style, but the buttons (Left, Center, Right) are in the same place on the Home tab.
  • Live Preview: In Excel 365, when you hover over an alignment button, you see a live preview of how your data will look – very helpful!
  • Keyboard shortcuts: Same in both versions – Ctrl+L (Left), Ctrl+E (Center), Ctrl+R (Right).

05

Entering Data

Learn how to type text, numbers, and formulas into cells.

Three types of data

  • Text (labels) （文字／標籤） – words, names, titles.
    "Student Name"
  • Numbers (values) （數值） – scores, prices, quantities.
    95, 3.5, -10
  • Formulas （公式） – calculations that start with =.
    =A1+B1
💡 Rule: Always start a formula with the equals sign (=). Otherwise, Excel treats it as text.

How to enter data

  1. Click the cell where you want to type.
  2. Type your text, number, or formula.
  3. Press Enter to confirm, or Tab to move to the next cell.
  4. You can also click the ✓ button on the formula bar to confirm.
Example: =5+3 → shows 8 in the cell.
▶ Excel 2024 vs Excel 365 – entering data
  • AutoComplete: Excel 365 has smarter AutoComplete – when you type a formula, it suggests functions and named ranges.
  • Dynamic arrays: In Excel 365, if you enter a formula like =A1:A5, it spills results into multiple cells automatically (new feature). Excel 2024 does not have this.
  • Data types: Excel 365 supports rich data types (stocks, geography) – not in Excel 2024.

Summary

  • The Excel window contains the ribbon, formula bar, grid, and sheet tabs.
  • The worksheet is made of columns (letters) and rows (numbers).
  • A cell address is the column letter followed by the row number (e.g., D7).
  • Use alignment buttons to make your table look professional.

▶ Excel 2024 vs Excel 365 – summary for home use
  • Most features are the same. Excel 365 has a few extra features (Tell Me search, spill arrays, rich data types), but all the basics work identically.
  • You can complete all homework using Excel 365 at home – just remember to look for the “Tell Me” box if you cannot find a command.
  • If a formula spills in Excel 365, that is normal – it means Excel is showing results in multiple cells automatically.
