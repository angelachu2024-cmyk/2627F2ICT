Lesson 01

The Excel Window and the Worksheet

This note explains how an Excel worksheet is arranged. It is written for Form 3 students, using simple words and examples.

1. The Excel Window

  1. The Excel window is your working area in Microsoft Excel.
  2. Inside the window, the main part is the worksheet grid (many small square boxes).
  3. You click cells in the grid to type text, numbers, and formulas.
Think of the Excel window as a classroom whiteboard. The worksheet is the graph paper on that whiteboard.
Excel Window (simplified diagram)

Column heading: letters at the top (A, B, C...)

Row heading: numbers on the left (1, 2, 3...)

2. The Worksheet

  1. The worksheet is a rectangular grid 正方形格子 with columns 欄 and rows 行.
  2. A column letter above the grid, also called a column heading, identifies each column.
  3. A row number on the left side, also called a row heading, identifies each row.
  4. Each intersection of a row and column creates one cell.
Maximum worksheet size: 16,384 columns and 1,048,576 rows
Total cells: 17,179,869,184
This is a very large space, so Excel can store huge amounts of data for tables, calculations, and charts.

3. Align Labels 對齊標籤

  1. You can align a label by using the alignment buttons on the Formatting toolbar 格式化工具列.
  2. First, click the cell that contains your label (text).
  3. Then choose an alignment button such as Align Left, Center, or Align Right.
  4. Use alignment to make headings and labels look neat and easy to read.
Align Left Center Align Right
Example: if table headers should be in the middle, select the header cells and click Center.
