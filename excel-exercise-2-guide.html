07

Set Data Validation

Restrict the type of data that can be entered in Cost Price, Selling Price, and Number of Items Sold.

Validation rules

Cost Price

Decimal > 0

Data → Data Validation → Decimal > 0

Selling Price

Decimal > 0

Data → Data Validation → Decimal > 0

Number of Items Sold

Whole number ≥ 0

Data → Data Validation → Whole number ≥ 0

Why validation?It prevents users from entering negative prices or fractional item counts, keeping data clean.
Custom messageIn the Data Validation dialog, go to the Input Message tab to add a prompt that appears when the cell is selected.
Remember: Data Validation does not affect existing data — it only restricts new entries. If you already have valid data, no change is needed.
Data Validation set for all three columns?
