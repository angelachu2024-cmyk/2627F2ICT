Charts in Excel

This lesson teaches you how to create and manage charts in Excel. You will learn to select data, insert different chart types, use chart tools, and move charts to separate chart sheets.

01

Chart Basics

Charts are a way of presenting and comparing data in a graphic format. A simple chart in Excel can say more than a sheet full of numbers.

Why use a chart?

  • A chart （圖表） presents data in a visual format, making comparisons easier.
  • Charts are dynamic – when the source data changes, the chart updates automatically.
  • Common chart types: column, bar, line, pie, and scatter.

  • Charts help you see trends, patterns, and outliers quickly.
💡 A chart is an object that is linked to a range of cells. It does not store data itself.

02

Inserting a Chart

Learn how to select a data range and insert a column, bar, pie, or line chart.

Steps to insert a chart

  1. Select the data range you want to chart (include headers if needed).
  2. Go to the Insert tab on the ribbon.
  3. In the Charts group, choose a chart type (e.g., Column, Bar, Pie, Line).
  4. Click the specific chart style (e.g., Clustered Column).
  5. The chart appears as an embedded chart on the worksheet.
💡 Always select the data before inserting the chart. If you select a single cell, Excel tries to guess the range.
▶ Excel 2024 vs Excel 365 – Inserting a Chart
  • Chart types: Excel 365 offers newer chart types like Funnel, Histogram, and Treemap.
  • Quick Analysis: Excel 365 has a "Quick Analysis" tool (appears near selected data) that suggests charts.

03

Chart Tools – Design and Format

Learn how to change the chart layout, style, switch rows/columns, and add elements like titles and data labels.

Design tab

  • Quick Layout – apply a predefined layout (title, legend, labels).
  • Change Chart Type – switch to a different chart type (e.g., pie to column).
  • Switch Row/Column – swap the data series between rows and columns.

Format tab

  • Format Selection – change the fill, border, and effects of chart elements.
  • WordArt Styles – format chart titles and axis titles.
  • Size – adjust the height and width of the chart.
💡 Click on any chart element (e.g., the legend, the title, or a data series) to select it, then format it individually.
▶ Excel 2024 vs Excel 365 – Chart Tools
  • Quick Layout – the Quick Layout button does not exist on Excel for the Web.
  • Change Chart Type – select the chart and select a new chart type directly as below.
  • Switch Row/Column

04

Chart Sheets vs. Embedded Charts

Learn the difference between an embedded chart and a chart sheet, and how to move a chart to its own sheet.

Two locations for a chart

  • Embedded chart （內嵌圖表） – placed on top of a worksheet, alongside data. Good for viewing data and chart together.
  • Chart sheet （圖表工作表） – a separate sheet in the workbook that contains only the chart. Good for printing or focusing on the chart.
  • To move a chart: select the chart -> Right Click -> Move Chart.
  • In the Move Chart dialog, choose New sheet and type a name (e.g., "Chart1").
💡 All charts are linked to the data selected. When you change any of the selected data, the chart also changes.

Why use a chart sheet?

  • Gives more space for the chart to be displayed.
  • Makes printing easier (prints without extra data).
  • Helps organize a workbook with multiple charts on separate tabs.
