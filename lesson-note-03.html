01

What is a Function?

A function is a built‑in formula that performs a specific calculation automatically.

Definition

  • A function （函數） is a predefined formula that Excel provides to help you perform common calculations quickly.
  • Instead of writing =A1+A2+A3+A4+A5, you can use =SUM(A1:A5).
  • Functions are designed to save time and reduce errors.
  • Excel has hundreds of functions for mathematics, statistics, finance, text manipulation, dates, and more.
=SUM(A1:A5)  →  adds all values in the range A1 to A5
[Key idea] Every function has a name (e.g., SUM) and arguments — the data the function needs to work. In =SUM(A1:A5), the argument is A1:A5.

Function syntax

  • Syntax （語法） is the structure or format of a function.
  • All functions start with an equals sign (=).
  • Then the function name, followed by parentheses ().
  • Inside the parentheses are the arguments （引數） — the inputs the function needs.
  • For example: =AVERAGE(B2:B10) — AVERAGE is the function name, B2:B10 is the argument.
Pro tip: You do not need to memorise all functions. Excel provides tools (AutoSum, Insert Function, and Help) to help you find and use the right function.
▶ Excel 2024 vs Excel 365 – Functions
  • Core functions (SUM, AVERAGE, COUNT, COUNTIF, MAX, MIN) work identically.
  • Excel 365 has newer functions like XLOOKUP, FILTER, SORT, UNIQUE — not in Excel 2024.
  • Excel 365 supports dynamic arrays — functions can spill results into multiple cells automatically.

02

Common Functions

Learn the six most frequently used functions for summarising data.

Function reference table

FunctionWhat it does （功能）Example
=SUM( ) Adds all values in a range （加總） =SUM(A1:A10)
=AVERAGE( ) Calculates the mean of values in a range （平均值） =AVERAGE(B2:B20)
=COUNT( ) Counts cells that contain numbers （計數） =COUNT(C5:C15)
=COUNTIF( ) Counts cells that meet a condition （條件計數） =COUNTIF(D:D, ">0")
=MAX( ) Finds the largest value in a range （最大值） =MAX(E3:E12)
=MIN( ) Finds the smallest value in a range （最小值） =MIN(F5:F25)
[Tip] COUNTIF uses a condition in quotes, e.g., ">0" for values greater than zero, or "Pass" to count cells containing the word "Pass".

Arguments explained

  • Arguments （引數） are the inputs you supply to a function.
  • In =MAX(A1:A10), the argument is A1:A10 — the range to check.
  • Some functions have multiple arguments, e.g., =COUNTIF(range, criteria).
  • Arguments can be:
    • Ranges — e.g., A1:A10
    • Single values — e.g., 10 or "Apple"
    • Other functions — e.g., =SUM(A1:A10, B1:B10)
Example: =COUNTIF(G5:G12, ">0") → G5:G12 is the range, ">0" is the condition.

AutoSum Button (Σ)

Learn how to use the AutoSum button to quickly insert SUM, AVERAGE, COUNT, MAX, or MIN — without typing any formula.

Where to find AutoSum

  • The AutoSum button （自動加總） is on the Home tab, in the Editing group (far right).
  • It looks like the Greek letter Σ (sigma).
  • Click the dropdown arrow next to it to see other options: Sum, Average, Count Numbers, Max, Min.
  • You can also find it on the Formulas tab, in the Function Library group.
[Tip] AutoSum guesses the range you want to calculate. Always check that the highlighted range is correct before pressing Enter.

How to use it — step by step

  1. Click the cell where you want the result to appear (e.g., below a column of numbers).
  2. Click the AutoSum button (Σ) on the Home tab.
  3. Excel highlights a suggested range. If it is correct, press Enter.
  4. If the range is wrong, drag to select the correct range, then press Enter.
  5. To use Average, Max, Min, or Count, click the dropdown arrow next to AutoSum and choose the function you need.
▶ Excel 2024 vs Excel 365 – AutoSum
  • Same button location – Home tab, Editing group, Σ symbol.
  • Excel 365 has a “Recommended” AutoSum suggestion that may appear when you select a range — it suggests the most likely summary.
  • Excel 365 also shows quick calculations in the status bar (sum, average, count) when you select a range — a handy way to preview results without inserting a formula.
  • The AutoSum button works identically. Use the status bar in Excel 365 to preview results.

Insert Function (fx)

Learn how to find and insert any Excel function using the Insert Function dialog — a powerful tool for discovering new functions.

Where to find Insert Function

  • The Insert Function button （插入函數） is next to the formula bar — it looks like fx.
  • You can also find it on the Formulas tab, in the Function Library group.
  • When you click it, the Insert Function dialog appears, where you can search for a function by name or by description.
  • When you insert a function this way, Excel automatically adds the = sign for you.

Typing Functions Directly

Learn how to type functions directly into cells — the fastest way when you know the function name.

How to type a function

  • Click the cell where you want the result and type the function directly.
=SUM(A1:A10)
=AVERAGE(B5:B20)
=COUNT(C1:C30)

Typing with cell references

  • You can type cell references directly, e.g., =A1+B1.
  • Or use ranges, e.g., =SUM(A1:A10).
  • You can also click and drag to select a range while typing — Excel fills in the range for you.
  • For functions like COUNTIF, remember the condition goes in quotes: =COUNTIF(G5:G12, ">0").
=COUNTIF(G5:G12, ">0")  →  counts cells in G5:G12 that are greater than 0

06

AutoFilter

Learn how to show only the rows that meet a condition using AutoFilter — a powerful way to focus on specific data.

What is AutoFilter?

  • AutoFilter （自動篩選） is a tool that shows only rows that meet a condition you set.
  • It does not delete data — it simply hides rows that do not match the filter.
  • You can filter by text (e.g., "contains A"), by numbers (e.g., "greater than 100"), by date, or by colour.
  • Filtered rows can be copied, formatted, or used for further analysis.
[Tip] AutoFilter is often used to find specific records, such as all students who passed, or all sales above a certain amount.

How to apply AutoFilter

  1. Select the range of cells you want to filter (include the header row).
  2. Go to the Data tab, in the Sort & Filter group, click Filter (or press Ctrl+Shift+L).
  3. Dropdown arrows appear in each header cell.
  4. Click the arrow in the column you want to filter.
  5. In the dropdown list, select or deselect items to set your criteria. Click OK to apply the filter.
  6. Only rows that match the criteria are now visible.

How to clear AutoFilter

  • To clear a filter from a specific column, click the dropdown arrow and choose Clear Filter.
  • To remove all filters and show all rows again, click the Filter button again on the Data tab (or press Ctrl+Shift+L again).
  • You can also use Clear in the Sort & Filter group.
[Tip] Filtering is temporary — your data is not changed. You can turn filters on and off anytime.
▶ Excel 2024 vs Excel 365 – AutoFilter
  • Same core features — AutoFilter works the same way.
