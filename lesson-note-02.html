Lesson 02

Numeric Labels and Editing a Worksheet

This lesson helps you understand when numbers are used as labels, and how to change the structure of a worksheet by inserting or deleting rows and columns. It also introduces Data Validation.

1. Numeric Labels and Values

Important idea

  • A numeric label is a number that is treated as text, not as a value for calculation.
  • To force Excel to treat it as a label, type an apostrophe first, such as '001.
  • The apostrophe does not appear in the cell, but it does appear in the formula bar.
  • Values usually align to the right of the cell; labels usually align to the left.

2. Insert and Delete Rows or Columns

  • When you insert a row or column, Excel creates space and shifts existing data.
  • When you delete a row or column, the data in that row or column is removed.
  • If data moves, formulas may also change, so always check your results again.
  • The format of the data moves with the data.

3. Data Validation

  • Data Validation is used to control what can be typed into a cell.
  • It helps reduce mistakes by allowing only the correct type of data.
  • Excel can show an input message when a cell is selected.
  • Excel can also show an error message when the data is invalid.
Example rules: Decimal greater than 0; Whole number greater than or equal to 0
This is useful for prices, quantities, and other fields that should not accept wrong values.
