01

Numeric Labels and Values

Understand the difference between a numeric label (text) and a numeric value (number), and how to force Excel to treat a number as a label.

Key Difference

  • Numeric value （數值） – a number that can be used in calculations (e.g., 5, 3.14).
  • Numeric label （數值標籤） – a number that is treated as text, not used in calculations (e.g., '001, '2024).
  • By default, Excel aligns values to the right, and labels to the left.
  • To enter a numeric label, type an apostrophe (') before the number, e.g., '001.
  • The apostrophe is not displayed in the cell, but it is shown in the formula bar.
💡 Why use labels? For IDs, codes, phone numbers, or any number that should not be added or multiplied.

▶Excel 2024 vs Excel 365 – Numeric Labels
  • Same behaviour – both versions treat apostrophe as a label prefix.
  • Excel 365 has a “Convert to Number” smart tag that may appear if you type a number as text – useful if you change your mind.
  • In Excel 365, you can also use the “Text” format from the Number Format dropdown to force a label without typing an apostrophe.
  • Both methods work in Excel 365. The apostrophe trick is the quickest.

02

Insert and Delete Columns/Rows

Learn how to add or remove columns and rows, and how this affects formulas and data organisation.

What happens when you insert or delete?

  • Insert （插入） – creates a new blank column or row. Existing data shifts to the right (for columns) or down (for rows) to make space.
  • Delete （刪除） – removes the entire column or row, and shifts remaining data to fill the gap.
  • Inserting or deleting can affect formulas – Excel automatically adjusts cell references, but you should always double‑check.
  • The format of the data will be moved or copied along with the data.
  • To Insert or Delete a row, select the number from the row heading. Right-click row number, click Insert or Delete on the shortcut menu.
  • To Insert or Delete a column, select a column number from column heading. Right-click column heading, click Insert or Delete on the shortcut menu.

💡 Warning: Deleting a row or column is permanent – you cannot undo after saving unless you use Ctrl+Z immediately.

Formulas and shifts

When you insert or delete, Excel updates formula references automatically. For example, if a formula was =SUM(B2:B5) and you insert a new row between, it becomes =SUM(B2:B6).

However, if you delete a row that is part of a formula range, Excel may adjust or show an error (#REF!) if the reference becomes invalid. Always check your formulas after editing.

03

Data Validation （資料驗證）

Control the type of data that users can enter into cells to prevent mistakes.

What is Data Validation?

  • Data Validation is a feature that restricts what can be typed into a cell.
  • You can set rules like whole numbers only, decimal > 0, dates in a range, or even a list of choices.
  • You can also display an input message when the cell is selected (to guide the user).
  • If the user enters invalid data, Excel shows an error alert with a custom message.
💡 Typical uses: Prices (must be > 0), quantities (whole numbers), IDs (text length), dates (in a semester).

Example rules

ColumnValidation ruleWhy?
Cost PriceDecimal greater than 0Prices cannot be negative or zero
Selling PriceDecimal greater than 0Same as cost
Number of Items SoldWhole number ≥ 0Cannot sell negative or fractional items
Date of SaleDate between 1/1/2024 and 31/12/2024Only sales in the current year

How to set it up

  1. Select the cell(s) you want to validate.
  2. Go to the Data tab → Data Validation.
  3. In the Settings tab, choose the Allow type (e.g., Decimal, Whole number, Date, List).
  4. Set the conditions (e.g., greater than 0).
  5. Optionally, set an Input Message (appears when cell is selected) and an Error Alert (appears when invalid data is entered).
  6. Click OK.

Quick Check

Questions

Summary

  • Numeric labels are entered with an apostrophe (') and are left‑aligned; they are not used in calculations.
  • Insert/Delete changes worksheet structure; formulas may update, but always double‑check.
  • Data Validation restricts input to specific types and values – it helps maintain data quality.
  • Always save your work after making structural changes.
