Guide 01

Getting Started with Microsoft 365 Excel

Follow this guide to sign in to Microsoft 365 at school, open Excel Online, create a blank workbook, rename the file with your own name, and download a copy to your computer. Work through the four steps in order.

What you need: your school username and password, and a computer with an internet browser (Edge, Chrome, or Safari).

Step 01

Access Microsoft 365 Excel

Excel Online lives inside your school Microsoft 365 account. You reach it through the school website and your school mailbox.

1.1  Open the school website

  1. Open your browser and go to https://shcces.edu.mo.
  2. Click the Intranet menu at the top of the page.
  3. From the drop-down list, click School Mail. （點選「School Mail」進入學校電郵）
School website → Intranet → School Mail
Careful: Do not click “eClass” or “Library” — the Microsoft 365 apps are inside School Mail.

1.2  Open the app launcher in Outlook

  1. Sign in with your school email address and password if you are asked to.
  2. Outlook opens. Look at the top-left corner of the page for the app launcher — a small grid of nine dots （九點方格）.
  3. Click the grid to open the Microsoft 365 apps list.
  4. You can type in the “Find Microsoft 365 apps” search box to narrow the list.
  5. Click Excel.
Outlook → app launcher → Excel
Reminder: The apps you see here (Word, Excel, PowerPoint, OneDrive …) are all part of your school Microsoft 365 account. Use the same launcher to open them next time.

Step 02

Create a Blank Workbook

A new Excel file is called a workbook （活頁簿）. Inside it are worksheets （工作表）.

How to create it

  1. On the Excel home screen, find the green button “Create blank workbook”.
  2. Click it once.
  3. Excel opens a brand-new workbook with one sheet, usually named Sheet1.
Excel Online home screen
Tip: If you already have a workbook open, you can create another one with File → New → Blank workbook.

What you should see

  • A Title Bar at the top showing the file name.
  • The Ribbon with tabs: File, Home, Insert, Draw, View …
  • A grid of columns (A, B, C …) and rows (1, 2, 3 …).
  • A Sheet tab at the bottom-left labelled Sheet1.
Your workbook is saved automatically to OneDrive — look for “Autosaved online to Documents” in the File menu.

Step 03

Rename the File

Your teacher needs to know the file is yours. Rename it using the class naming rule before you start typing any data.

Naming rule

F2B00_YourName_HW01
  • F2B00 — your class and your classnumber.
  • YourName — your own English name (no spaces).
  • HW01 — the homework number.

How to rename it

  1. Look at the top-left corner of the Excel window, next to the green Excel icon.
  2. Click once on the current file name (for example Book1 or Untitled spreadsheet).
  3. The name becomes editable and a tooltip says “Rename file”.
  4. Delete the old name and type your new name, for example F2B00_YourName_HW01.
  5. Press Enter to confirm.
Click the file name → type the new name → press Enter
Check your name carefully. A wrong file name makes it hard for your teacher to find and mark your work. Use underscores (_), not spaces.

Step 04

Download a Copy

Excel Online saves your work in the cloud. To keep a copy on your own computer or to hand it in, you must download it.

How to download

  1. Click the File tab on the ribbon (top-left).
  2. In the left-hand menu, hover over Create a Copy.
  3. A sub-menu appears. Click Download a Copy.
  4. Your browser saves the file, usually into the Downloads folder.
File → Create a Copy → Download a Copy
File type: The downloaded copy is an .xlsx file — the normal Excel workbook format. You can open it later in desktop Excel or upload it back to OneDrive.
