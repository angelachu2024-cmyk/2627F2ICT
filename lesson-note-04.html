01

IF Function Syntax

Understand the structure of the IF function and how it returns one of two results based on a logical test.

“IF” Function

  • “IF” function is useful when the value you want to assign to a cell is dependent on a logical test.
  • A logical test is made up of two expressions and a relational operator. Each expression can be a cell reference, a number, text, a function, or a formula.

Syntax

=IF(logical_test, value_if_true, value_if_false)
  • logical_test （邏輯測試） – a condition that is either TRUE or FALSE, e.g., A1>=60.
  • value_if_true （真值） – the result if the test is TRUE.
  • value_if_false （假值） – the result if the test is FALSE.
  • Text results must be enclosed in double quotes, e.g., "PASS".
  • Numbers do not need quotes, e.g., 3 or 0.
IF is one of the most frequently used functions in Excel – it helps you automate decision‑making in your worksheets.

Visual example

For example: B4=100, B18=99
=IF( B4>=$B$18
logical test
 , "This is true"
value if true
 , "That is false"
value if false
 )
  • If cell B4 is greater than or equal to the value in cell B18, then it displays “This is true”.
  • If cell B4 is less than the value in cell B18, then it displays “This is false”.

Logical Operators

Learn the symbols used to build logical tests in IF and other functions.

Comparison operators

OperatorMeaning （意義）Example
> greater than （大於）  =IF(SUM(T4:T9)>300, 0, 1)
< less than （小於）  =IF(J17/B5<12, $B$15, B13-5)
= equal to （等於）  =IF(C5=K7, B29-F3, K5+S3)
>= greater than or equal to （大於或等於）  =IF(A15>=$R$2, C4*H5, 6)
<= less than or equal to （小於或等於）  =IF(H5+F5<=10, $H$10, 9*B3)
<> not equal to （不等於）  =IF(C5<>$B$5, "OK", "Not OK")
These operators are used in logical tests. For example, =IF(D5>=60, "PASS", "FAIL") uses the >= operator.

03

Absolute References in IF （IF 中的絕對參照）

When comparing each row to a fixed value (e.g., class average), use absolute references to lock the comparison cell.

Why absolute reference?

  • Suppose you want to give 3 credits to students whose average is at least the class average.
  • The class average is in a single cell, e.g., B18.
  • If you write =IF(G5>=B18, 3, 0) and drag down, the reference to B18 will change to B19, B20, etc. – which is incorrect.
  • You must lock the cell using dollar signs: $B$18.
=IF(G5 >= $B$18, 3, 0)
Absolute reference （絕對參照） keeps the row and column fixed when copying. Use F4 to toggle between relative and absolute.

Conditional Formatting （條件式格式）

Learn how to automatically change the appearance of cells based on their values.

What is Conditional Formatting?

  • Conditional Formatting （條件式格式） applies formatting (font colour, fill colour, borders) only when a condition is met.
  • It does not change the cell value – only the appearance.
  • Common uses: highlight scores below 60 (red), above 80 (green), or duplicates.
  • You can find it on the Home tab, in the Styles group.
For Exercise 04, you will highlight Final Average values greater than 80.00 using Conditional Formatting.

How to apply

  1. Select the range of cells you want to format (e.g., G4:G10).
  2. Go to Home → Conditional Formatting → Highlight Cells Rules → Greater Than.
  3. Enter the threshold value (e.g., 80).
  4. Choose a formatting style (e.g., Light Red Fill with Dark Red Text) and click OK.
Tip: You can also use Less Than, Between, Equal To, or even create custom rules with formulas.
